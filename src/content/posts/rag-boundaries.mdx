## چرا مرز مهم است

بدون مرز مشخص، سامانه ممکن است به اسنادی پاسخ دهد که کاربر حق دیدن آن‌ها را ندارد، یا پاسخی بدهد که منبعش روشن نیست.

## لایه‌های کنترل

- احراز هویت و نقش‌ها قبل از بازیابی سند
- فیلتر مجموعهٔ اسناد بر اساس واحد سازمانی
- نمایش استناد به منبع در پاسخ نهایی

```ts
type RetrievalPolicy = {
  roles: string[];
  collections: string[];
  requireCitation: boolean;
};
```

## جمع‌بندی

RAG سازمانی یک قابلیت نمایشی نیست؛ یک مسیر مهندسی با سیاست داده و مشاهده‌پذیری است.
